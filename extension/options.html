Provider Usage Dashboard

Extension settings

Connect the extension to a dashboard running on localhost, a trusted LAN, or a VPN. The extension reads /api/usage; credentials remain on the dashboard host.

Enter the base URL only. HTTP is allowed for localhost and trusted private networks.

Security note

Only grant access to an endpoint you trust. The API omits credential values, but provider responses can include account email and plan metadata. Do not expose the Python server to the public internet.
